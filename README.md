# UpTier public website

This repository contains the public product, privacy, terms, support, data-deletion, and empty mobile-layout preview pages for UpTier.

The UpTier application source is maintained separately in a private repository. Do not submit financial files, account information, provider credentials, API keys, or access tokens to this repository.

Public website: https://dhunter6409.github.io/uptier-site/

Mobile layout preview: https://dhunter6409.github.io/uptier-site/app-preview/

Reviewed future Firebase account-portal target: https://uptier-502917.web.app/auth/

Firebase Hosting uses an exact allowlisted artifact with local and remote SHA-256 verification. The canonical public origin remains GitHub Pages until the exact Firebase version is live and verified. See [the release runbook](docs/FIREBASE_HOSTING.md). No Firebase credentials belong in this repository.
