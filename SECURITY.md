# UpTier Website Security Policy

UpTier takes the security and privacy of its website and financial-planning services seriously. Please report suspected vulnerabilities privately rather than opening a public GitHub issue.

## Reporting a vulnerability

Email [uptier.support@gmail.com](mailto:uptier.support@gmail.com) with the subject `UpTier website security report` and include:

- The affected page or URL
- A clear description of the issue and its potential impact
- Reproduction steps that do not expose another person's information
- Your contact information for follow-up

Do not send passwords, access tokens, Plaid secrets, MFA codes, recovery codes, bank credentials, complete account numbers, or unredacted financial records. If sensitive evidence is necessary, first send a brief description and request a secure transfer method.

We aim to acknowledge reports within two business days, investigate them promptly, and coordinate remediation and disclosure when appropriate.

## Supported version

The version currently published from the default branch of this repository is supported. Older deployments and copied versions are not supported.

## Responsible testing

Please do not:

- Access, modify, retain, or disclose another person's data
- Perform denial-of-service or high-volume automated testing
- Use social engineering, phishing, or physical attacks
- Disrupt the website or connected services
- Publicly disclose a vulnerability before UpTier has had a reasonable opportunity to investigate and address it

Good-faith reports that follow this policy are appreciated.
